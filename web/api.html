Syscalls POSIX + bloque NEWOS y toolbox /bin

Los números 0–318 son los de Linux x86_64 para el subconjunto implementado; las llamadas propias viven en el bloque 450+. Mecanismo: int $0x80 (trap gate DPL3). rax = número, rdi rsi rdx r10 r8 r9 = args (SysV), retorno en rax (≥0 ok, <0 error −1). rcx/r11 clobbered, resto preservados. Punteros validados con copy_from/to_user. Bounce estático 512 B. Usa el buscador para filtrar.

Toolbox /bin (30 + hello + init)

ComandoQué hace
ls / cat / echoLista (perms d/rwx), dump en bucles de 512 B, echo con -n.
mkdir [-p] / rmdir / rm / touchUn nivel + mkdir -p userland; rm con fix de rutas anidadas.
pwd / cd / clearcd es builtin; clear = 25 \n.
uname [-srm] / hostname / whoami / idhostname lee/escribe /etc/hostname; whoami/id parsean /etc/passwd real.
date / uptime / sleep / free / dfCMOS, sysinfo (total/free/uptime/hz); df en bytes, free en KB.
ps / kill [-9]Tabla ps; kill protege init.
wc / head / grep -i / sortFiltros de texto clásicos.
about / newfetchabout: uname+sysinfo+/etc/version/hostname+MIT. newfetch: logo + root@host, OS/Kernel/Uptime/Memory/Shell/Display/Packages.
ltestSelf-test de libc (string/stdio/heap). Exit 0 solo si todo PASS.
img <bmp|ppm>Visor BMP 24/32 + PPM P6 sobre framebuffer. JPEG/PNG rechazados con mensaje.
vidAnimación procedural 60 frames ~15 fps (bola + plasma).
desktopCompositor: ventanas solapadas draggables, close boxes, cursor con backing store, barra de memoria, readout /dev/mouse.
newpkgGestor .new: info verify install remove list files. Ver página de paquetes →
hello / init (nsh)hello: entry propia sin nshlib/libc ("Hello from ring 3!"). init: la shell.
Añadir un comando: crea user/programs/<cmd>/<cmd>_main.c con main(argc, argv) y regístralo en PROG_NAMES (Makefile) + bin_table (initramfs.c). Ojo: OBJS := es expansión inmediata — el *_EMBED va antes de OBJS.

libc propia (libc.a)

Freestanding: string (mem*/str*), stdlib (abs/atoi/rand/exit), stdio sin buffer (putchar puts printf %s %d %u %x %X %p %c %%), malloc/free/calloc/realloc con arena 256 KiB. Sin floats/locale/threads/FPU. Solo ltest la linka. nshlib (user/lib/nshlib + start.S + app.ld): wrappers int $0x80 con macros SYSC0-3 + helper fail().
