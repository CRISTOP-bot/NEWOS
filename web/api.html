Syscalls 0–21 y toolbox /bin

Mecanismo: int $0x80 (trap gate DPL3). rax = número, rdi rsi rdx r10 r8 r9 = args (SysV), retorno en rax (≥0 ok, <0 error −1). rcx/r11 clobbered, resto preservados. Punteros validados con copy_from/to_user. Bounce estático 512 B. Usa el buscador para filtrar.

#NombreFirmaNotas
0SYS_READread(fd, buf, len)fd 0 bloquea en consola; resto VFS. Short counts. Máx 512 B.
1SYS_WRITEwrite(fd, buf, len)Escribe al file del fd. Máx 512 B.
2SYS_EXITexit(code) noreturnTermina el proceso.
3SYS_GETPIDgetpid()PID del llamante.
4SYS_SLEEPsleep(ms)Deadline persistente que sobrevive re-traps; cede a peers.

6SYS_WAITPIDwaitpid(pid)Exit code del hijo; PIDs desconocidos fallan, nunca cuelgan.
7SYS_OPENopen(path, flags)O_READ=1 O_WRITE=2 O_CREATE=4. Fds por proceso.
8SYS_CLOSEclose(fd)Libera el fd.
9SYS_MKDIRmkdir(path)Un nivel (mkdir -p vive en userland).
10SYS_READDIRreaddir(path, buf, bytes)Cuenta hijos capada por buffer (nsh_dirent name[64] mode size).
11SYS_CHDIRchdir(path)cwd por proceso.
12SYS_GETCWDgetcwd(buf, size)Falla si el buffer es pequeño.
13SYS_UNLINKunlink(path)Ficheros y dirs vacíos; rehúsa no-vacíos.
14SYS_SPAWN2spawn2(path, argv, argc)argv real 16×128. Lo que usa nsh.
15SYS_PSps(buf, bytes)Tabla (nsh_proc pid ppid state name[32]).
16SYS_KILLkill(pid)Rehúsa pid 0/1 (init sagrado). Señal base+9.
17SYS_UNAMEuname(&u)NEWOS 0.2.0-pre-alpha x86_64 (sysname/release/machine).
18SYS_GETTIMEgettime(&t)CMOS real 24 h (year mon day hour min sec).
19SYS_SYSINFOsysinfo(&si)frames total/free, uptime, hz.
20SYS_FBINFOfbinfo(&fi)Geometría (present width height pitch bpp); 0 sin Limine.
21SYS_FBWRITEfbwrite(&rq)Blit XRGB8888 (x,y,w,h,pixels,pixlen), por filas, bounds-checked.
No implementados: lseek / stat / truncate / rename · mmap / sbrk · sockets · señales. Fallan como syscall desconocida. Structs compartidos en abi/syscall_abi.h (NSH_MAX_ARGS=16 ARGLEN=128 PATH=256).

Añadir un comando: crea user/programs/<cmd>/<cmd>_main.c con main(argc, argv) y regístralo en PROG_NAMES (Makefile) + bin_table (initramfs.c). Ojo: OBJS := es expansión inmediata — el *_EMBED va antes de OBJS.

libc propia (libc.a)

Freestanding: string (mem*/str*), stdlib (abs/atoi/rand/exit), stdio sin buffer (putchar puts printf %s %d %u %x %X %p %c %%), malloc/free/calloc/realloc con arena 256 KiB. Sin floats/locale/threads/FPU. Solo ltest la linka. nshlib (user/lib/nshlib + start.S + app.ld): wrappers int $0x80 con macros SYSC0-3 + helper fail().
