Instalar la ISO descargada

QEMU (recomendado). qemu-system-x86_64 -cdrom web/dl/newos-x86_64-limine.iso -boot order=d -m 128M -serial stdio — verás el mismo arranque de las capturas.
USB real. sudo dd if=newos-x86_64-limine.iso of=/dev/sdX bs=4M status=progress && sync (revisa bien el of=: borra el disco entero).
VirtualBox. Crea máquina Linux Other 64-bit ≥128 MB, monta la ISO como CD/DVD, BIOS legacy (no EFI) y arranca.

Probar sin instalar nada

# interactivo (serie)
make qemu
# ISO Limine con gráficos
make qemu-limine
# suite automatizada → exit 1 = PASS
make qemu-test
make qemu-limine-test
# UEFI (OVMF)
qemu-system-x86_64 -cdrom build/images/newos-x86_64-limine.iso \
  -boot order=d -m 128M -serial stdio -display none \
  -drive file=/usr/share/ovmf/x64/OVMF_CODE.4m.fd,if=pflash,format=raw,unit=0,readonly=on \
  -drive file=/tmp/ovmf_vars.fd,if=pflash,format=raw,unit=1
# captura de pantalla:
# -monitor unix:/tmp/mon,server,nowait → screendump /tmp/s.ppm

VirtualBox / hardware

Adjunta la ISO como CD/DVD · máquina Linux Other 64-bit · ≥128 MB · BIOS legacy (no EFI) · GRUB en serie 115200 8N1 · el kernel siempre espeja en VGA 80×25. Detalle: docs/virtualbox-and-hardware.md.

Toolchain cruzada (opcional)

bash toolchain/build.sh --jobs 2   # binutils 2.44 + GCC 16.1.0 C-only → toolchain/out/ (~20-40 min)
export PATH="$PWD/toolchain/out/bin:$PATH"
make CROSS_PREFIX=x86_64-elf- all
make CROSS_PREFIX=x86_64-elf- qemu-test   # debe dar QEMU exit status: 1
bash toolchain/test.sh
