v0.3.0-gui actual

Añadido

  • /proc y /sys de solo lectura con identidad, uptime, memoria, montajes y inventario PCI.
  • free, df y uptime leen /proc con fallback a sysinfo.
  • Autosanación de PRs con GitHub Actions + CodeRabbit OSS.
  • Escritorio, iconos de marca y paquetes .new integrados en la ISO.

Unreleased en desarrollo

Añadido

  • Entrada Linux syscall x86-64 + BusyBox 1.35.0 estático oficial (402 applets) en /bin/busybox, con fallback de nsh por applet.
  • /bin/glxgears TinyGL embebido (300 frames), limpieza de panel y SYS_CONSOLE_GUI para que los logs del kernel no ensucien el framebuffer.
  • Escritorio modular propio: main/state/gfx/wm/theme/shell/apps/input/compositor/surface/widgets, cinco ventanas (System, Files, Mouse, About, Log), dock, menú, ayuda y repintado por rectángulos sucios (damage) con subida de 16 filas por SYS_FBWRITE.
  • Sesión gráfica opcional: entrada Limine NEWOS (GUI) con gui=1, make qemu-limine-gui, teclado PS/2 1–6 y retorno limpio a nsh.
  • Superficies y widgets propios (desktop_surface, desktop_widgets): painter, gradientes, botones, barras y separadores sin código GPL, sustituyendo el slice NTK.
  • VOXEL (MIT) vendorizado en ports/voxel y embebido como /bin/voxel: stack de superficies/compositor + escritorio clásico (taskbar, Start, File Explorer), compilado con scripts/build-voxel.sh.
  • Identidad BoredOS/Win95: bandera de cuatro paneles, iconos bevelados para el escritorio y todo /bin, temas BoredOS/Win95/Periwinkle, wallpaper Limine 1920×1080 y splash 640×400.
  • Syscalls SYS_OPEN (7) y SYS_CLOSE (8) + test fase-2 open-close.
  • Fix GCC 16 / C23 (bool en core_types.h).
  • PMM multi-run: registra cada región E820, nunca MMIO como RAM.
  • Consola de texto VGA 80×25 (máquinas sin serie, p. ej. VirtualBox).
  • Config GRUB robusta (serie + VGA) e ISO GRUB reproducible byte-idéntica.
  • Sistema de paquetes .new completo (formato NEW1, /bin/newpkg, builder host, hello-new-1.0.0, make check-newpkg).
  • Doc docs/virtualbox-and-hardware.md.

Corregido · Verificado

  • vfs_unlink split_parent comía el primer carácter del basename (rompía rm anidado y el remove de paquetes).
  • Cursor duplicado/fantasma: el kernel pintaba su flecha y restauraba celdas viejas sobre el compositor. Ahora el cursor es overlay de staging, se dañan los rectángulos viejo/nuevo y la flecha legacy se suspende con SYS_CONSOLE_GUI.
  • newpkg install reinstalaba GNU coreutils en cada shell; ahora detecta la misma versión y --force sigue reparando.
  • BOOT=PASS SeaBIOS + OVMF · REPRO ISO GRUB byte-idéntica.
