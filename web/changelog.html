Fuente: CHANGELOG.md del repo. Versión actual: 0.2.0-pre-alpha.

Unreleased en desarrollo

Añadido

  • Syscalls SYS_OPEN (7) y SYS_CLOSE (8) + test fase-2 open-close.
  • Fix GCC 16 / C23 (bool en core_types.h).
  • PMM multi-run: registra cada región E820, nunca MMIO como RAM.
  • Consola de texto VGA 80×25 (máquinas sin serie, p. ej. VirtualBox).
  • Config GRUB robusta (serie + VGA) e ISO reproducible byte-idéntica.
  • Sistema de paquetes .new completo (formato NEW1, /bin/newpkg, builder host, hello-new-1.0.0, make check-newpkg).
  • Doc docs/virtualbox-and-hardware.md.

Corregido · Verificado

  • vfs_unlink split_parent comía el primer carácter del basename (rompía rm anidado y el remove de paquetes).
  • BOOT=PASS SeaBIOS + OVMF · REPRO ISO byte-idéntica.
