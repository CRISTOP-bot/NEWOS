Arquitectura y capas

Kernel monolítico freestanding. Un fichero = un dominio, prefijo por directorio, prohibidos utils.c common.c misc.c main.c desnudos. Se auditó y rechazó reorganizar en kernel/ sched/ graphics/ gui/: churn alto sin ganancia.

Secuencia de arranque

1 · Carga
QEMU / GRUB / Limine cargan el ELF. En vía nativa el trampolín 32-bit crea el paging (identidad + high-half) y salta a long mode.
→
2 · arch_main
Normaliza la RAM (multiboot2 / PVH / Limine), siembra el PMM run a run, levanta GDT·TSS·IDT·serie y el VMM.
→
3 · kernel_boot_main
Monta initramfs, crea procesos, registra syscalls, corre 14 self-tests y salta a /init en ring 3.

Vía nativa (PVH / Multiboot2)

1. Trampolín 32-bit x86_entry.S:_start (solo BSP): paging 4 niveles en .early_bss — identidad baja 1 GiB + high-half 0xffffffff80000000. Activa PAE + long mode, salto lejano a C.
2. arch_main: normaliza RAM (multiboot2 0xe85250d6 o PVH 0x336ec578), PMM por cada run E820 (nunca MMIO), GDT/TSS, IDT 256 + int $0x80 DPL3, VMM, heap temprano 4 MiB.
3. kernel_boot_main: sched, tests, /bin/hello si test_mode=1 si no /init, salto a ring 3.

Vía Limine (framebuffer)

Ya en long mode + HHDM. Copia runs usables, snapshot del framebuffer, mapea el panel UC en ventana privada y registra fbcon junto a serie/VGA. Pide entry, HHDM, memmap, cmdline y framebuffer. Release v12.9.0 cacheada en build/limine-bins/.

Memoria: PMM + VMM + heap

PMM

Bitmap + buddy sobre todos los rangos RAM usables (pmm_allocator_init_ranges, clamp a direct-map). MMIO jamás entregado. APIs pmm_frame_alloc/free, pmm_block_alloc/free, phys_reserve/release_range.

VMM

4 niveles, espacios por proceso, mitad kernel heredada, mitad usuario validada. Flags PRESENT/USER/WRITE/NX. copy_from/to_user validados; copy_user_string byte-a-byte.

Heap

Arena temprana 4 MiB + kmalloc/kfree. libc userland con arena estática 256 KiB (sin sbrk; NULL si se agota).

VFS y rootfs generado

VFS con open/read/write/close/mkdir/create/lookup/unlink/readdir, cwd por proceso, modos DIR/REG, flags O_READ/O_WRITE/O_CREATE. Backends tmpfs (RAM) + devfs + initramfs. Al boot se genera: /dev /proc /sys /tmp /etc /bin /sbin /lib /usr /home /root /run /opt /var /mnt, dotfiles (hostname passwd motd version), pics splash.bmp test.ppm, 30 bins, sample /tmp/*.new. Límites honestos: solo RAM volátil, sin disco, sin lseek/stat/truncate/rename/mmap/sbrk, I/O 512 B por syscall.

Shell nsh y gráficos userland

nsh (/init, /bin/sh · 534 líneas)

Edición UTF-8: flechas, Home/End, Delete, historial 16, Ctrl+A/E/U/W/K/Y/V/C/D/L, kill-ring, quoting, builtins cd exit help history clear, externos vía spawn2/waitpid. Prompt root@newos:<cwd>#.

img · vid · desktop (solo Limine FB)

img: BMP 24/32 sin compresión + PPM P6 (JPEG/PNG rechazados con mensaje: necesitan heap+FPU). vid: animación procedural 60 frames ~15 fps (bola + plasma) vía FBWRITE+SLEEP. desktop: compositor con ventanas draggables, close boxes, cursor con backing store, barra de memoria, readout de /dev/mouse, microfuente 3×5.

Compilar y ejecutar

make all            # kernel → build/images/newos-x86_64.elf (+ lint-layers)
make limine         # variante Limine → build/images/newos-x86_64-limine.elf
make iso            # ISO GRUB multiboot2 reproducible
make build/images/newos-x86_64-limine.iso   # ISO híbrida BIOS+UEFI
make qemu           # interactivo serie
make qemu-test      # suite PVH 14 tests (exit 1 = PASS)
make qemu-limine-test / make qemu-limine / make qemu-network / make qemu-disk
make check-newpkg   # paquetes sin QEMU (80+ asserts + 19 e2e)
make toolchain      # binutils 2.44 + GCC 16.1.0 C-only (~20-40 min)
make clean          # borra build/ entero

Flags kernel: -ffreestanding -nostdlib -fno-pic -fno-pie -mno-red-zone -mno-sse -mgeneral-regs-only -mcmodel=kernel -O2 -Werror, link con PHDRS explícitos (ningún PT_LOAD RWE). Userland: ELF estático en 0x400000, stack 1 MiB bajo 0x7fffffffe000, embebido vía ld -r -b binary → initramfs /bin/*.

VirtualBox y hardware real

ISO no híbrida/MBR: adjuntar como CD/DVD, máquina Linux Other 64-bit, ≥128 MB, BIOS legacy (no EFI), menú GRUB en serie 115200 8N1; el kernel siempre espeja en VGA. Serie opcional COM1 0x3F8 IRQ4. Validado en SeaBIOS + OVMF + PVH. Detalle completo en docs/virtualbox-and-hardware.md.
