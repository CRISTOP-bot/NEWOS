Gestor nativo

Paquetes .new

Contenedor determinista NEW1 (header 48 B + metadata + manifest + payload, CRC32 IEEE en todo), CLI /bin/newpkg, builder host y base de datos en /var/lib/newpkg. Primer paquete real: hello-new-1.0.0-x86_64.new.

CLI newpkg

newpkg info <pkg.new>     # metadata + lista de ficheros + CRCs
newpkg verify <pkg.new>   # integridad total incl. payload
newpkg install [--force] <pkg.new>  # validado con rollback
newpkg remove <name>      # borra ficheros + DB
newpkg list               # name + version (readdir /var/lib/newpkg/*.info)
newpkg files <name>       # dump .files

Pipeline de install

magia → CRCs → lens → keys → arch (uname -m) → release (≥ newos-min) → deps (DFS depth 16, detecta ciclos A→B→A) → conflictos (absent / mismo pkg / --force) → extracción streameada 512 B sin seek (unlink-antes-de-reescribir) → registro <name>.info + .files con installed-at CMOS. Fallo = rollback (unlink creados + DB parcial).

Límites honestos v1

Sin update/search/install <name> por repo (requiere red + persistencia + firmas; CRC32 detecta corrupción, no malicia). Sin compresión (bit0 reservado) ni firmas (spec v2). Replace = unlink+create (ventana de crash hasta reinstall). Permisos viajan en manifest pero sin enforcement UID/mode.

Ciclo de vida de un paquete

Describe. Escribe tu packages/mi-app.newspec (nombre, versión, arch, ficheros + modos).
Construye. python3 tools/newpkg/newpkg-build.py genera el .new determinista (bytes idénticos en cada build).
Verifica. make check-newpkg corre 80+ asserts unitarios y 19 tests end-to-end sin QEMU.
Instala. Copia el .new al NEWOS vivo y newpkg verify + newpkg install (con rollback si algo falla).
Gestiona. newpkg list / files / remove contra la DB de /var/lib/newpkg.

Formato NEW1

ParteContenido
[header 48 B]LE: magia NEW1, spec 1, flags 0, meta_len 1–4096, manifest_len 1–16384, payload_len 0–8 MiB, CRCs header/meta/manifest/payload, file_count 1–256, reserved 0.
[metadata]key:value\n LF ordenado. Requeridos: name version arch desc license maintainer build newos-min (+ opcional depends "b (>=1.0), c", ops = == >= <= > <).
[manifest]Ordenado: octmode size-dec crc-hex8 abspath, 2 MiB/fichero.
[payload]Raw concatenado en orden del manifest, sin compresión.

Nombre: <name>-<version>-<arch>.new. Paths absolutos 2–255 chars [A-Za-z0-9._+~@%=-/], sin //, sin ./.., bajo /bin /sbin /lib /etc /usr /opt /var /home /root /tmp; rechaza /dev /proc /sys /init /.

Crear un paquete (.newspec)

# packages/hello-new.newspec
name="hello-new" version="1.0.0" arch="x86_64"
desc="Hello world smoke-test" license="MIT" maintainer="NEWOS"
build="make build/packages/..." newos-min="0.2.0" depends=""
files: build/userland/hello.elf /bin/hello-new 0755

# construir + probar (sin QEMU):
python3 tools/newpkg/newpkg-build.py   # bytes deterministas, LF, sin timestamps
make check-newpkg                       # unit 80+ asserts + e2e 19 tests

Mapa v1: core portable newpkg_format.h/.c (sin syscalls/libc/FPU) · CLI newpkg_main.c → /bin/newpkg · builder newpkg-build.py · driver host-test.c · jail posix-shim.c ($NEWPKG_HOST_ROOT) · suite tests/test_newpkg.py. Docs: docs/packages.md new-format.md newpkg.md.
